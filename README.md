# 号码整理工具

把**文本**或**图片（手写数字）**整理成固定书写格式，支持「全倒」「3字X」「批量 =N」，
右侧结果可以手动编辑，最后**一键全部复制**（每行一组）。

左侧输入、右侧输出，Windows 上可当独立小窗口用，手机上也能打开同一套界面。


---

## 1. 怎么运行（Windows）

1. 安装 [Node.js](https://nodejs.org/)（LTS 版，一路下一步即可，只需装一次）。
2. 双击 **`启动（Windows）.bat`**。
3. 浏览器会自动打开（Edge/Chrome 会以**独立窗口**方式打开，看起来就是一个客户端）。
   黑色命令行窗口是服务窗口，**关掉它程序就退出**。
4. 首次使用点最左侧竖栏里的 **设置**，填入通义千问（阿里云百炼）的 API Key，点「保存并测试」。

> 手机上用：确保手机和电脑在同一个 Wi-Fi 下，打开命令行窗口里显示的
> `http://192.168.x.x:8765` 即可；在浏览器菜单里选「添加到主屏幕」会像 App 一样打开。

### macOS

双击 `start-mac.command`（首次需右键 →「打开」，或在终端执行 `chmod +x start-mac.command`）。

### 不想装 Node.js？

直接用浏览器打开 `public/index.html` 也能用**全部文本功能**（粘贴即校验 / 全倒 / 3字X / 编辑 / 全部复制）。
正式使用请通过 GitHub Pages 的 HTTPS 地址打开。OCR 由浏览器直接请求用户填写的接口，服务商须支持 CORS，无需 OCR 后端。

## 2. OCR 接口配置（通义千问）

每位用户在「设置」中填写自己的服务商、HTTPS 接口地址、模型和 API Key。
站点不提供默认密钥，不读取旧的 `config.local.json`。默认仅保存于当前浏览器会话；勾选「记住密钥」后保存至该浏览器本地存储。清除密钥可以移除保存的凭证。

阿里云公共兼容接口示例：`https://dashscope.aliyuncs.com/compatible-mode/v1`。
业务空间密钥请填写匹配的专属域名。图片和密钥仅发送到填写的服务商地址，API 费用由用户自己承担。

### 图片点选与标注

两栏和三栏布局的「全倒」「3字X」均优先处理输入框中的文本选区；没有文本选区时，处理图片点选对应的高亮号码；都没有选择时处理全部输入。生成结果按批次覆盖输出框。

上传、拖入或粘贴图片后，主页面从两栏切换为三栏：第一栏显示原图与点选标注，第二栏显示首次识别结果，第三栏显示二次处理结果。上传后自动定位号码；点击号码切换选中状态，也可拖过多组，再输入 `=N` 进行标注。

电脑端三栏并排对照，导航收进汉堡菜单；手机端通过“图片 / 输入 / 输出”切换，保留完整编辑宽度。定位完成后全部合规号码写入中间输入栏，标注同步更新对应号码的 `=N`。点选和缩放不会覆盖手动编辑；重新标注会更新本次选中号码对应的行，已删除的号码经确认后重新写回，其他手动编辑保留。原有输入、输出操作和各自的“全部复制”继续使用；“全倒”“3字X”“格式整理”按批次覆盖第三栏。图片操作区显示“已定位 X 组，已标注 X 组”。

同批多张图片可以切换查看，各图的选择与标注独立保留，识别结果按图片顺序汇总到中间栏。再次上传会更换图片批次；图片栏右上角的关闭按钮收起图片并恢复两栏，保留已有输入和输出内容。

支持滚轮／双指缩放。放大后可通过滚动条、空格加拖动或鼠标中键移动图片。

### OCR 只保留合规号码（自动过滤）

识别结果在进入输入框之前会过滤一遍：**只留下符合规则的 3~4 位号码组合**，其它一律丢掉。

图片上写的是 | 输入框里得到
---|---
`42×4=168（元）` | `42X4`（`=` 后面的算式结果整段丢弃）
`49×1=49（元）` | `49X1`
`4×94` | `4X94`（`×` 转成大写 `X`）
`4394` / `4284` | 原样保留
`12345678` | 丢弃（连续 5 位以上不截断，避免错误拆分）
`XXX4` / `X23` | 丢弃（不合规），但会列在提示里，可一键放回手动改

被丢掉的内容不会静默消失：输入框下方会显示「已过滤 N 段不符合格式的内容」，
点「查看全部 / 放回输入框」可以看到并还原。

**一段合规的都没有时，输入框不会被写入任何东西**（不会把垃圾塞进输入框），只弹提示。
其中"看起来像号码但不符合格式"的片段（如 `42713` —— 多半是把大括号 `}` 读成了数字）
会单独列为**疑似误读**，并给出**疑似修正建议**：

```
64915 → 6491      42910 → 4291
[采用疑似修正（2 组）]
```

点一下就写进输入框（你核对一下即可）。程序**不会自动替你改**，因为去掉哪一位属于猜测；
但大多数情况下去掉最后一位就是对的（大括号在号码右边）。

### 手写照片识别不准怎么办

程序里的默认提示词是**针对手写号码纸实测调优过的**（明确写了"大括号 `}` 不是数字"、
"输出前自检：出现 5 位就说明读错了"），实测这类照片能稳定读对。如果换一类照片还是不准：

1. 把照片**裁剪到只剩号码部分、拍正**（背景、桌面、其他字都会干扰）；
2. 在「设置」→「识别提示词（高级，留空用默认）」里补充说明，例如
   「号码是红笔写的」「忽略表格线」「大括号后面是金额」；
3. 换模型对比：`qwen-vl-ocr-latest`（默认，手写号码表现最好）、`qwen3.5-ocr`。
   （实测通用模型 `qwen-vl-max-latest` 在号码纸上容易臆造数字，不建议。）

手动粘贴的文本**不会**被这样过滤 —— 那边的原则仍然是"标红提示、不擅自删改"。

* 识别不准时，可以把模型换成 `qwen3.5-ocr`、`qwen-vl-ocr-2025-11-20` 或通用的 `qwen-vl-max-latest` 再试。
* 「通义千问 · DashScope 原生接口」支持图片自动转正，拍歪的照片更适合；切过去不用改地址。
* 用别的服务（任何 OpenAI 兼容的视觉接口）时，选「其他 OpenAI 兼容服务」，自己填地址和模型。
* 密钥也可以通过环境变量 `DASHSCOPE_API_KEY` 提供，不写进文件。
* 图片会先在浏览器里压缩到最长边 1800px 再上传，省流量也更快。
* 想验证配置是否可用：设置弹窗里点「保存并测试」，会真发一张 96×96 的小图过去。

> 参考文档：[文字提取（Qwen-OCR）](https://help.aliyun.com/zh/model-studio/qwen-vl-ocr)、
> [通过 OpenAI 接口调用通义千问 VL 模型](https://help.aliyun.com/zh/model-studio/qwen-vl-compatible-with-openai)、
> [获取与配置 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)

## 3. 规则说明

### 号码格式

| 情况 | 是否合法 | 例子 |
|---|---|---|
| 4 位纯数字 | ✅ | `1234`、`0123`（保留前导 0） |
| 4 位含 1~2 个 X | ✅ | `X234`、`XX34`、`X2X4` |
| 4 位含 3~4 个 X | ❌ | `XXX4`、`XXXX` |
| 3 位纯数字 | ✅ | `123`、`012` |
| 3 位含 X | ❌ | `X23`、`XX3` |
| 其它位数 | ❌ | `12345`、`12345678`（**不会自动拆分**，需你确认分组） |

* 粘贴内容里的 `+` `*` `x` `×` 一律转写成大写 `X`；全角数字 `１２３４` 自动转半角。
* 非法内容**标红并提示原因**，不擅自删除、不猜测；修正后再复制出去。
* 识别存疑的位用 `?` 占位（例如 `1?34`），同样需要修正。

### 格式整理（把左侧内容就地变合规）

点左侧「格式整理」，把输入框里的一坨文本**就地**整理成「每行一个号码」，**同时同步一份到右侧输出框**：

| 整理前 | 整理后 |
|---|---|
| `1234、X234、XX34、123` | 四行 `1234`/`X234`/`XX34`/`123` |
| `12+4、56*8` | `12X4`/`56X8` |
| `1234=2.5` | `1234=2.5`（**合法的 `=N` 后缀保留**） |
| `42×4=168（元）` | `42X4`（整段不合法时救出等号左边的号码） |
| `XXX4`、`X23`、`12345678` | 过滤掉，并在下方提示「已过滤 N 段」 |

被过滤的内容会列在提示里，点「查看全部 / 放回输入框」能找回来；整错了按左侧「撤销」退回。

### 全倒

对每个 **4 位纯数字** 生成全部不重复排列（包含原号码），单组内部自动去重。
**每个输入号码自成一组，组与组之间空一行。**

| 输入 | 组数 |
|---|---|
| `1234` | 24 |
| `1224` | 12 |
| `1122` | 6 |
| `1112` | 4 |
| `1111` | 1 |

输入 `1234、1224` → 先是 `1234` 的 24 组，空一行，再是 `1224` 的 12 组。

### 3字X

先输出**全部原号码**，再依次把第 1、2、3、4 位替换成 `X`。
**原号码 / 第1位 / 第2位 / 第3位 / 第4位 各成一组，组与组之间空一行。**

输入 `1234、5678` →

```
1234            ← 原号码
5678

X234            ← 第 1 位变 X
X678

1X34            ← 第 2 位变 X
5X78

12X4            ← 第 3 位变 X
56X8

123X            ← 第 4 位变 X
567X
```

### =N 后缀

* 勾选若干行（或点「全选」）→「批量添加 =N」→ 输入数值，例如 `2.5`。
* N 可以是 `0`、正整数、正小数；**不允许负数**。
* 手写时这些写法都算合规：`1234=2`、`1234 = 2`（等号两边带空格）、`1234=2.5`、`1234=.5`、`1234=2.`、`1234=+2`、以及全角 `１２３４＝２`——校验前会先做字符归一化。
* 已有后缀会被**直接替换**；「清除后缀」可以去掉。
* 未选任何行时，默认对全部行生效（弹窗里会写明）。

### 重复号码

* 重复只看号码部分：`1234=2` 与 `1234=3` 算重复，**不会自动合并或相加**。
* 发现重复会提示，你可以选「去重」（保留首次出现）或「保留」；**保留不算错误，可以直接全部复制**。
* 全倒单组内部的重复（如 `1224` 的排列）已自动去掉。

### 全部复制

* 右侧底部的主按钮，一键把**右侧当前内容**整段复制到剪贴板（含手动编辑和 =N 后缀）。
* 全倒 / 3字X 生成的分组空行**固定一起带上**。
* 手写/粘贴进来的**全角数字、全角＝、全角ｘＸ、`+ * ×`** 在校验时就已归一化，复制出去的同样是规范写法。
* 右侧还没有内容时会提示，不会往剪贴板塞空内容。
* 快捷键 `Ctrl/Cmd + S` 已随导出一起下线（现在按下去不会触发浏览器的「保存网页」）。

> **导出 TXT 暂时下线**：实现完整保留在 `public/app.js` 的 `exportTxt()` 里（含异常行拦截、重复号码二次确认、文件名带时间戳），
> 需要时把按钮或快捷键接回去即可。

## 4. 界面速览

| 位置 | 说明 |
|---|---|
| **左边文本框** | 粘贴文本；也支持把图片拖进来、直接 `Ctrl+V` 粘贴截图。**粘贴即校验**：不合规的号码在原文位置直接标红（鼠标停上去看原因），行数徽标同步显示「N 行 · M 组（K 异常）」 |
| 识别图片 | 点「上传图片」或粘贴截图 → 展开三栏并自动定位 → 首次结果写入中间输入栏 → 点选标注或使用输入栏操作生成右侧处理结果 |
| 全倒 / 3字X | 按上面的规则生成右侧内容；不适用的号码会给出提示，可选择追加到结果末尾 |
| 生成结果 | 全倒 / 3字X 固定**替换**右侧内容（想保留旧结果就先复制走） |
| **右侧大文本域** | 解析结果**每行一组**放在同一个文本框里，随便改、随便粘贴、随便删行；全倒 / 3字X 的结果按组空行分隔 |
| 行内标色 | 异常行**红色**、重复号码**橙色**，文本域下方还有可点击的问题列表（点一下跳到那一行） |
| 批量 =N / 清除后缀 | **先在文本域里选中若干行就只改这些行**；不选则对全部行生效 |
| **选择组**（左右两个输入框都有） | 以**空行**为界，一键选中光标所在的**一整组**（连续若干行）；已经是整组选区时再点一次会往下多选一组。配合「批量 =N」可以给一整组号码统一加后缀 |
| 去重 | 一次去掉全部重复号码（保留第一次出现的） |
| **撤销**（左右各一个） | **两侧历史互相独立**：左侧可撤销打字 / 粘贴 / 清空 / 套用疑似修正；右侧可撤销图片生成、全倒 / 3字X、去重、批量 =N 和手动编辑。连续打字（800ms 内）只算一步；历史最多 40 步，刷新页面后清空 |
| **全部复制** | 右侧底部的主按钮：把右侧当前内容整段复制到剪贴板（每行一组，空行自动忽略，全角会转成规范写法） |
| **按钮分组** | 操作区按功能分组：管理类（撤销 / 清空）和选择类（全选 / 选择组）两组**靠上**，其余功能自动归为一组**靠下**；左右两侧规则一致，没有的功能就不显示该按钮 |

内容会自动存在浏览器本地，关掉再打开还在（换浏览器或清缓存会丢）。

> 实现小细节：文本域里文字本身是透明的，真正的文字由下面一层同样字体的高亮层渲染，
> 这样才能做到"在输入框里直接标红"，两层滚动是同步的。

## 6. 安全提醒

* API Key 仅保存在用户浏览器，OCR 请求直连用户指定服务商；共享设备不要勾选记住密钥。
* 服务默认监听 `0.0.0.0`（为了让手机能访问）。只想自己用可以改成
  `HOST=127.0.0.1 node server.js`，这样局域网里其他设备就连不上了。
* **不要把 `config.local.json` 发给别人**，也不要把密钥贴到聊天工具里。

### 图片点选标注

上传图片后立即进入点选模式，并调用视觉模型定位号码（DashScope 的 OCR 专用模型使用 qwen-vl-max 完成定位，普通 OCR 设置不变）。定位完成后点击号码可选中，再点一次取消，第三次重新选中；拖动经过多组时，每组也按当前状态切换一次。支持三位纯数字与四位合规号码混合出现，定位结果在本次窗口中复用。

定位需要模型能返回号码坐标；失败或无结果时可重试，框选 / 涂画入口暂时隐藏。候选框需核对，模型可能遗漏或定位偏移；连续长数字不会按固定长度强制拆分。前端修改后刷新页面；公网版本通过 Release 发布。

点选定位会忽略顶部标题、序号、金额备注和大括号，逐组保留合规号码；按原图像素坐标定位，再转换为画布坐标。模型返回无效位置时会明确提示，避免误报为没有合规号码。

### 图片内分批标注 =N

在图片栏中，点击单组或拖过多组号码，第二栏对应号码同步高亮。图片只用边框表现选择状态，不叠加“号码=N”文字；已有标注保留颜色区分。输入数值并点击「标注选中号码」（也可按 Enter），每批完成后自动清空本批选择，保留已有标注。支持 0、小数和重新选中后改值。若第二栏对应号码已删除，点击或拖选结束后会询问是否重新填回；取消不恢复，确认只恢复选中且缺失的号码。

首次识别结果（包括未标注号码）写入中间输入栏；图片标注更新中间栏对应行。第三栏通过输入栏的处理操作生成，方便对照原图、首次结果和处理结果。两侧文本均可编辑并独立撤销，不同位置的重复号码保留。
